// Pixel-Perfect Web to PDF Export Guide (React & Tailwind CSS)
// This guide documents the exact architecture and CSS rules required to render pixel-perfect, multi-page PDF exports directly from any React & Tailwind CSS dashboard or web page.

// 1. The Core Problem in Modern Dashboard Apps
// In modern web applications (like React dashboards), layouts typically use:

// h-screen or max-h-screen
// overflow-hidden on parent wrappers
// overflow-y-auto on <main> or content containers
// Why Standard Printing Fails:
// Single-Page Clipping: The browser sees h-screen and overflow-hidden on the layout container, clipping the printed output to 1 single screen height.
// Scrollbars in PDF: The browser renders inner scrollbars inside the PDF preview instead of flowing content onto Page 2, 3, etc.
// Broken Layouts: Forcing display: block in @media print destroys Tailwind flexbox rows (flex), grids (grid), side-by-side metric cards, and badge alignments.
// Missing Colors: By default, browsers strip background colors, gradients, and custom badge fills to save ink.
// 2. The 4 Golden Rules for Perfect Web-to-PDF
// Rule 1: Remove Screen Height Caps (Without Breaking Layouts)
// Override .h-screen, .overflow-hidden, and .overflow-y-auto only in @media print to set height: auto !important and overflow: visible !important.

// Rule 2: Never Touch .flex or .grid Displays
// Keep Tailwind flexbox and grid rules intact. Do NOT force display: block !important on containers.

// Rule 3: Force Exact Color Printing
// Use -webkit-print-color-adjust: exact !important; and print-color-adjust: exact !important; so all background colors, gradients, blue accent buttons, and badges print with 100% fidelity.

// Rule 4: Prevent Card Clipping (break-inside: avoid)
// Apply break-inside: avoid; to card containers (.rounded-3xl, .rounded-2xl, etc.) so individual cards do not split awkwardly mid-card across page boundaries.

// 3. The Master CSS Snippet (Plug & Play)
// Add the following snippet at the end of your global CSS file (e.g. src/index.css):

// css

// /* Page Setup for A4 Printing */
// @page {
//   size: A4 portrait;
//   margin: 10mm;
// }
// @media print {
//   /* 1. Hide non-printable UI elements (sidebars, navbars, export buttons) */
//   header,
//   aside,
//   nav,
//   .no-print {
//     display: none !important;
//   }
//   /* 2. Unlock height & overflow for multi-page flow (Preserves Flex & Grid) */
//   html,
//   body,
//   #root,
//   .h-screen,
//   .w-screen,
//   .overflow-hidden,
//   .overflow-y-auto,
//   .overflow-x-auto,
//   main {
//     height: auto !important;
//     min-height: 0 !important;
//     max-height: none !important;
//     overflow: visible !important;
//   }
//   /* 3. Force exact background colors & clean page margins */
//   body {
//     background: #ffffff !important;
//     padding: 0 !important;
//     margin: 0 !important;
//     -webkit-print-color-adjust: exact !important;
//     print-color-adjust: exact !important;

//   main {
